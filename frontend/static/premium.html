Project Overview

SentientShield • ML Detector is a premium resilience platform that integrates the NeuralFort framework for real-time web threat monitoring, autonomous healing actions, and secure model inference. This dashboard centralizes health, anomalies, insights, and model prediction tooling.

How to Run

  1. Ensure dependencies are installed from requirements.txt in a virtualenv.
  2. Start the API server: python -m uvicorn api.main:app --host 127.0.0.1 --port 8000 or run scripts/start_uvicorn.bat.
  3. Open the dashboards:
    • /static/premium.html — Overview
    • /static/neuralfort_dashboard.html — NeuralFort Control Center
    • /static/dashboard.html — Model Dashboard
